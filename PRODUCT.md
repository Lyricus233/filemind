# FileMind

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

The demo uses React, TypeScript, Vite, and React Router alongside the existing NestJS API.

## Users

The project is a learning tool and a personal document collection. Its web interface lets the operator upload material, inspect processing, and verify where a search result comes from.

## Capabilities and Constraints

- Open at the search workbench. File management has its own route.
- Accept text, Markdown, text-based PDF, and DOCX. Expose the processing status and the resulting passages.
- Return keyword matches and semantic scores through their respective API modes. Show page or paragraph locations where available.
- Keep the interface restrained and academic. Use real API results for the working demo.
